# 活动整理 Skill

## 何时使用

- 我想办一个活动
- 帮我整理一下活动流程
- 记录一下这次活动
- 把这个活动写成文档
- 更新某个活动的流程
- 把详细版浓缩成简洁版
- 根据简洁版补全详细版

## 目标

为每个活动生成：

1. **简洁版**：`activities/<活动名>/README.md`，一个文件看完
2. **详细版**：`activities/<活动名>/details/`
   - `README.md` 索引
   - `roles.md`
   - `checklist.md`
   - `timeline.md`
   - `templates/`

并登记到：

- `activities/README.md`
- 根 `README.md`

## 能力

| 能力 | 说明 |
|---|---|
| 从零整理活动 | 引导用户补全信息，生成简洁版 + 详细版 |
| 详细版 → 简洁版 | 读取 `details/`，浓缩成 `README.md` |
| 简洁版 → 详细版 | 读取 `README.md`，引导补充信息，拆成 `details/` |
| 登记活动 | 更新 `activities/README.md` 和根 `README.md` |

## 工作流程

### 场景 A：从零整理活动

1. 确认活动基本信息：名称、英文目录名、一句话、性质、人数、时长、核心原则
2. 按简洁版模板逐项引导：快速流程、分工、提前准备、报名、当天流程、安全、复盘
3. 生成 `activities/<活动名>/README.md`
4. 生成 `activities/<活动名>/details/`
5. 登记到 `activities/README.md` 和根 `README.md`
6. 提示用户确认

### 场景 B：详细版 → 简洁版

1. 读取 `activities/<活动名>/details/`
2. 提取核心信息：
   - 活动定位
   - 快速流程
   - 分工（表格）
   - 提前准备（要点）
   - 当天流程（要点）
   - 安全与合规
   - 复盘
3. 生成或更新 `activities/<活动名>/README.md`
4. 在简洁版顶部保留指向详细版的链接
5. 提示用户确认

### 场景 C：简洁版 → 详细版

1. 读取 `activities/<活动名>/README.md`
2. 识别缺失信息，向用户提问补充：
   - 分工是否要细化
   - 检查清单是否要逐项列出
   - 时间线是否要按阶段拆
   - 是否需要报名模板、歌单模板等
3. 生成或更新 `activities/<活动名>/details/`
4. 在详细版索引顶部保留指向简洁版的链接
5. 提示用户确认

### 场景 D：登记活动

1. 在 `activities/README.md` 表格中追加或更新一行
2. 在根 `README.md` 活动列表中追加或更新链接

## 输出规范

- 简洁版必须有，详细版推荐有
- 简洁版要能独立看懂
- 详细版要能直接执行
- 两版之间互相链接
- 安全、合规、环保内容必须写

## 引导话术示例

- “这个活动大概多少人参加？”
- “需要提前准备哪些东西？”
- “当天流程大概分几段？”
- “有没有安全或合规方面要注意的？”
- “预算大概多少？”
- “要不要我把详细版浓缩成简洁版？”
- “要不要根据简洁版补一份详细版？”

## 注意事项

- 不一次问太多，分批引导
- 用户没想到的点，主动给建议
- 生成后让用户确认再写入
- 不要覆盖已有内容，除非用户确认
- 文件路径按仓库规范：`activities/<活动名>/README.md` 和 `activities/<活动名>/details/`
